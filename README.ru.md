## 📦 Установка и Настройка

### Системные требования

Убедитесь, что у вас установлен [Node.js](https://nodejs.org/) версии 18.x или новее.

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/S1ach/AdminPanel.git
cd AdminPanel
```

### Шаг 2: Установка зависимостей

```bash
npm install
```

### Шаг 3: Запуск сервера разработки

```bash
npm run dev
```

Откройте адрес [http://localhost:3000](http://localhost:3000) в вашем веб-браузере для просмотра приложения.

### Шаг 4: Сборка и запуск продакшн-версии

Для создания оптимизированной сборки и запуска:

```bash
npm run build
npm run start
```

## 📖 Архитектура Проекта

Структура каталогов спроектирована по методологии Feature-Sliced Design (FSD) для обеспечения масштабируемости:

```
src/
├── app/                  # Инициализация приложения (стили, провайдеры, роутинг, глобальный стор)
│   ├── (dashboard)/      # Защищенные разделы и макеты панелей
│   │   ├── calendar/     # Страница интерактивного календаря задач
│   │   ├── orders/       # Управление списком заказов
│   │   ├── products/     # Каталог товаров
│   │   ├── settings/     # Настройки профиля, тем и локализации
│   │   └── users/        # Управление пользователями
│   ├── api/              # Реализация серверных эндпоинтов (API)
│   └── store/            # Конфигурация Redux Store
├── entities/             # Бизнес-сущности (analytics, users, products, orders)
├── shared/               # Переиспользуемые примитивы UI, переводы i18n, иконки, типы
└── widgets/              # Композиционные блоки страниц (sidebar навигации, шапка header)
```

### Настройки путей (Path Aliases)

Для удобного абсолютного импорта файлов в tsconfig настроены алиасы:

- `@app/*` указывает на `src/app/*`
- `@widgets/*` указывает на `src/widgets/*`
- `@features/*` указывает на `src/features/*`
- `@entities/*` указывает на `src/entities/*`
- `@shared/*` указывает на `src/shared/*`
